# ChooseSA — South African Course & Career Guide

A simple website that helps students in South Africa compare universities, colleges, and TVET institutions, discover suitable study paths, and understand career opportunities before enrolling.

## Features
- Search by study field, level, province and institution type
- Course recommendations based on student interests
- South African career guide for common study paths
- Enrollment steps for local students
- Responsive mobile-friendly layout

## Run locally
Open the `index.html` file directly in a browser, or run a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project files
- `index.html` — main page structure
- `styles.css` — styling and layout
- `app.js` — course data and recommendation logic

## Notes
This version is a polished website prototype. You can later connect it to a real backend, a university application form, or a live course database.
